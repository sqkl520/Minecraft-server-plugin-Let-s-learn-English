## 0. 总判决（15 票合成）

**工程是真诚的，产品是未验证的。** 所有视角殊途同归：代码卫生、i18n、防御性、
文档纪律在业余项目里属超纲（R6:"它不是烂码，是没有第二双眼睛的码"）；但"教会英语"
这个核心命题**从未被任何证据触碰过**——词库缺 NGSL 头部 29/30 个功能词（R2 实锤）、
判分信号被同释义干扰项污染（R2/R3）、间隔重复是无回忆质量的常量表（R2）、
奖励挂"做了题"不挂"学会了"（R3）、AI 纠错花真金白银买来却在落错题本前一步丢弃（R9）、
与 MC 世界零耦合使"强制学习"只是文案（R1）、GitHub 2 star / 0 fork / 全 SNAPSHOT
发行、97 条 findings 无一条来自真实用户（R13/R15）。

**R15 的判决最有分量但需打折**：它自己也在反魔鬼自检里承认——"零用户证据"可能只是
"零用户度量"（渠道分发查不到），语气应从"推倒"降到"先停下来量一量"。

## 1. 共识致命伤（多源互证，按证据链强度排序）

### C1 闭环断裂：系统各处都在"学完就丢"【5 源】
- R3：答对即发币挂"做了题"，答错当场泄答案、1h 后再考=背答案
- R9：AI corrections 只 sendMessage 不落实物；花出去的 API 钱断在闭环前一步
- R12：AI 场景与词库两条内容线互不相通（prompt 不含词库进度）
- R2：AI 推荐"接下来学的 3 个词"只打印一行；corrections 不进复习队列
- R10：决斗打完什么都不留下（零持久化 config.yml:161 自陈）
**裁决：全票成立，为最高优先级问题族。**

### C2 数据访问无边界：一致性靠注释纪律【4 源】
- R5：14 张缓存三套真相语义、40 处手写 synchronized(getConnectionLock())
- R6：data/ 外 17 处裸 getConnection()、38 处方言分叉散布 6 文件（编排者实测复核数一致）
- R7：答对一题 6~9 条串行 SQL 过同一全局锁；自动保存全量重写无 dirty flag
- R15：同族 bug 繁殖力（锁外取连接被不同 agent 反复独立发现，只修点名处；
  残余台账自认 DailyChallengeManager ~8 处 / AchievementManager 4 处未扩面）
**裁决：成立。这是 10-18 修复模式的结构性天花板——点止血可无限繁殖。**

### C3 部署级地雷：文档承诺与产物事实不符【3 源，本轮新发现】
- R7+R11 双源实锤：**MySQL 后端开箱即炸**——mysql-connector-j compile-scope 无 shade，
  产物 JAR 内 com/mysql 类 0 个（编排者 unzip 复核），wiki 通篇教配 MySQL 却不提驱动
- R11+编排者实锤：**语言文件升级即硬覆盖**——config-version 落后即 saveResource(...,true)，
  服主自定义文案全丢，.bak 单槽
- R11+编排者实锤：**改 AI key 后 /lea reload 无效**——aiChatManager.reload() 唯一调用点
  是 GUI 按钮，HotReloadManager 不覆盖 ai-chat 段，wiki 却指导服主用 reload
- R1：README"发音辅助"=一声叮（无 sounds.json/pack.mcmeta，四源共证 TTS 从未接入客户端：
  R1/R2/R7/R9）
- R1：LICENSE GPL-3 vs README MIT vs pom 无 licenses 段——法务自相矛盾
**裁决：全部属实。R14"文档告诉新人 -DskipTests"同源——文档在系统性说谎（非恶意，是无对账）。**

### C4 经济体系是演的【3 源】
- R3：产出 8 路径、消耗 1 路径且默认关、money.enabled 默认 false="净产出 0 净消耗 0"
- R1：三大宣传卖点（赛季/班级/仪表盘）全部默认关——"作者自己都不敢让用户开箱碰到"
- R10：金币榜是排行榜第一个 tab，money 关着时恒为 0 的空榜
- R11："装完答对没钱"是头号工单来源（README 未提默认关）
**裁决：成立。要么把经济做成真闭环（加 sink），要么删掉叙事。**

### C5 可观测性为零（性能+业务双面）【3 源】
- R7：无慢查询/锁等待埋点、无 bStats
- R11："金币怎么没发"五道闸无一处可查、发币无台账、缺 Vault 零日志（实锤）
- R9：API 从不读 usage 字段、无 token/费用日志、无全服预算（实锤：grep usage 零命中）
- R15：漏斗分析必需的 created_at/last_login 死列零写入（DatabaseManager:115 原注释自陈）

### C6 资损与漏洞面【2 源，本轮新发现】
- R9 实锤：开场白 R-16 通道"不计轮次不查上限" + startConversation 清冷却 =
  反复开关场景可零冷却无限刷服主的 DeepSeek 账单
- R4 实锤：WordLearningGUI/ClassBoardGUI 空槽无 fillEmpty + 下半区不 cancel +
  无 MOVE_TO_OTHER_INVENTORY 拦截 = duel 修过的丢物品洞在主学习界面原样存在
- R10：choice 蒙对与认真拼写同分同连击，daily-limit 只砍钱不砍分 = 刷榜比认真省力

### C7 核心手感：输入通道绑死最差路径【2 源】
- R4：选项画在 GUI 里点不动（实锤：slot 13 lore 渲染、点击侧只认 4 功能槽）；
  手机/Geyser 玩家一个字母 5 步；IME 全角字符无归一化判错进错题本；
  cancel/goodbye 既是教学词又是退出指令（实锤在库）；提醒不可拒
- R1：全项目无可点击消息组件（run_command/hoverEvent grep 0，编排者实锤）——
  发现性全靠不可点的纯文本

### C8 内容枯竭【2 源】
- R2：NGSL 头部功能词 29/30 缺失 + c/d 字母灌水 + breath/breathe 撞车释义成双解题
- R12：勤奋学生 20 词/天 50 天见底；dialogues/ 目录是空的；difficulty_level 运行时零消费
**裁决：死于没内容的概率大于死于没功能。**
